# PINGGO - Mobile Web Social App

A sleek, responsive mobile social networking template featuring real-time interactive chats, friend management, wallet top-ups, and an exclusive **Secret Drop** content monetization model.

## Features
- 💬 **Interactive Messaging**: Mobile chat interface with auto-response simulation.
- 🔒 **Secret Drop**: Paywall media sharing model with dynamic unlocking via Gems currency.
- 💎 **Wallet System**: PINGGO Gems balance tracking & instant simulated top-ups.
- 📱 **iOS/Mobile Optimized**: Ultra-responsive layout tuned for mobile browsers & desktop viewports.
- 🎨 **Modern Design**: Pink & Slate Gray glassmorphism aesthetic with floating bottom navigation.

## How to Deploy on GitHub Pages
1. Upload `index.html` and `README.md` to your GitHub repository.
2. Go to **Settings** > **Pages** in your repository.
3. Select the `main` branch as the source and click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repository-name>/`.
